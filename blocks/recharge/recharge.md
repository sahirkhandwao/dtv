# Recharge Widget

The Recharge widget is a dedicated form for quick account recharges. It is designed to be placed in the same section as a hero banner, where it will automatically overlay on the top-right corner.

## Authoring

To author the block, create a table (or individual block cells) with 3 parts. 

| Part | Content | Description |
|---|---|---|
| 1 | **Heading** | The title of the widget (e.g., "Instant Recharge"). |
| 2 | **Placeholder** | The help text inside the input field (e.g., "Enter Registered Mobile No. OR VC No."). |
| 3 | **Button Text** | The text on the action button (e.g., "PROCEED"). |

## Layout Behavior

- **Desktop**: The widget is positioned absolutely to the top-right of its parent section. It has a custom rounded corner on the bottom-left to blend into the banner area.
- **Mobile**: The widget transforms into a standard block element that stacks relative to the banner.
