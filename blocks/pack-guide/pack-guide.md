# Pack Guide Block

The Pack Guide block creates a split-screen interactive guide. On desktop, clicking a section header updates the visual element on the right. On mobile, it functions as a single vertical accordion.

## Block Variations

This block currently does not have any variations. It always uses the theme and layout described.

## Interaction Behavior

- **Desktop**: Split layout. Left has the accordion, right has the dynamic image.
- **Mobile**: Full vertical accordion. The image appears below the description within the expanded section.
- **Auto-collapse**: Selecting a new section automatically collapses the previously active one.
