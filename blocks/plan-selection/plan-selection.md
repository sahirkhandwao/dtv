# Plan Selection Block

The Plan Selection block displays a comparison grid of subscription plans. On mobile, it automatically transforms into a swipeable carousel.

## Authoring

Create a table with 8 columns. The structure is fixed to map specific content to card areas.

### Row 1: Main Title
The first row should contain the large section heading (e.g., "Dish HD Entertainment **Starts Here**").

### Row 2: Subtitle
The second row should contain the subheader text (e.g., "Simple plans. Great value.").

### Card Rows (Row 3 onwards)
Each subsequent row represents one plan card. Use exactly 8 columns:

1.  **Badge Text**: Pill label at top (e.g., "HD Plan With Pack").
2.  **Plan Name**: Small descriptive name (e.g., "Dish HD").
3.  **Price**: The large price text (e.g., "₹ 1355*").
4.  **Price Subtext**: Smaller info below price (e.g., "With Three Months Pack").
5.  **Product Image**: Image of the set-top box.
6.  **Key Features**: A bulleted list of features.
7.  **Value-Add Icons**: A bulleted list where each item contains an **Image** and a **Text** label.
8.  **Link**: A link for the "SELECT" button.

### Footer Rows (Last 2 Rows)
1.  **Disclaimer**: Small text usually aligned right (e.g., "*GST Extra. T&C Apply.").
2.  **Bottom CTA**: Full-width text at the very bottom (e.g., "Unsure which offer? Call 1800...").
